# Screen Bridge

Android-приложение для захвата экрана телефона и последующей передачи изображения AI-помощнику.

## Текущий этап: 0.1.0

В репозитории создан стартовый Android-проект:
- Kotlin + Jetpack Compose;
- экран приложения;
- запрос системного разрешения Android на захват экрана через MediaProjection;
- отображение результата разрешения;
- кнопки «Начать» и «Остановить».

**Важно:** в версии 0.1.0 ещё нет фактической записи, трансляции или отправки кадров. Кнопка «Остановить» пока меняет только состояние интерфейса. Захват экрана будет добавлен следующим этапом с использованием foreground service и соблюдением ограничений Android.

## Сборка
Открой проект в Android Studio. Для сборки нужны JDK 17 и Android SDK 35.

## План
1. Проверить запуск приложения на Samsung.
2. Реализовать захват кадров через MediaProjection и корректную остановку сессии.
3. Добавить защищённую передачу изображения на компьютер/сервер.
4. Добавить камеру как отдельную функцию с отдельным разрешением.
5. Настроить сборку APK и тестирование на телефоне.
